# Morro's Vapos — GitHub + Firebase

Proyecto preparado para publicar en GitHub Pages y guardar los datos de forma compartida con Firebase.

## Antes de publicar
1. Crea un proyecto en Firebase.
2. En Authentication habilita "Email/Password".
3. Crea una base de datos Firestore.
4. Registra una aplicación Web.
5. Copia la configuración de Firebase y reemplaza los valores `REEMPLAZAR` en `app.js`.
6. Crea los usuarios Juan y Morro en Firebase Authentication.
7. Sube los archivos a GitHub.
8. Activa GitHub Pages desde Settings > Pages > Deploy from branch > main > /(root).

## Importante
No pongas contraseñas de usuarios dentro del código. Firebase Authentication se encarga de ellas.
